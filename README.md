# GapLens AI — Career Pivot Coach
A standalone career-pivot coaching MVP.

## Features
- PDF/DOCX resume upload and text extraction
- Target-role and pasted job-description intake
- Resume-to-job skill comparison and gap map
- Week-by-week learning plan
- Portfolio project suggestions mapped to gaps
- Mock interview question bank and four-part self-scoring rubric
- SQLite job application tracker

## Run on Windows PowerShell
```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Honest limitations
Skill extraction uses a built-in keyword list and exact text matching, not semantic AI. Job descriptions are pasted by the user, not fetched live. Learning plans and portfolio suggestions are template-generated. Interview scoring is self-assessed, not automated. Application records are stored locally in SQLite.

## Improved learning roadmap and portfolio recommendations
The roadmap now provides one official/recognized learning resource, a practical exercise and a measurable weekly milestone for each detected missing skill. Portfolio recommendations are project-specific, with a purpose, feature checklist and explicit skill-gap mapping. These recommendations are rule-based templates, not generated by a live AI model. Review resource links and project fit before presenting them.
